# AI Sales Agent - Prototype

An AI-powered sales agent that generates personalized cold emails and LinkedIn DM drafts based on industry and offer inputs.

# Link of web 
app:  https://ai-sales-agent-dht9yhvsdm4y26ebpulirb.streamlit.app/

## 🚀 Features

- **Industry-Specific Content**: Generates content tailored to your target industry
- **Dual Output**: Creates both email and LinkedIn DM drafts
- **Professional Templates**: 3 unique drafts for each format
- **Download Functionality**: Save generated content as text files
- **Best Practice Tips**: Built-in guidance for effective outreach
- **Responsive UI**: Clean, professional Streamlit interface
